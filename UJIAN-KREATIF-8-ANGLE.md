# Ujian Kreatif Meta Ads — 8 Angle Siap Guna

> Kaedah anda: **1 Ad Set · 5–8 poster · angle ayat berlainan**.
> Dokumen ini memberi 8 angle siap copy-paste + cara uji supaya data bersih.

---

## 1. KAEDAH ANDA — BETUL, TAPI ADA SYARAT

Anda betul: **audiens sama, kreatif berbeza** = mengasingkan pembolehubah kreatif.
Itu cara paling bersih untuk tahu ayat mana yang menarik.

**Tapi ada 2 syarat supaya data tak menipu:**

### Syarat 1 — Bajet mencukupi untuk setiap poster

| Bilangan poster | Bajet harian minimum | Sebab |
|---|---|---|
| 3 poster | RM60/hari | RM20/poster |
| 5 poster | RM100/hari | RM20/poster |
| **8 poster** | **RM160/hari** | RM20/poster |

> **Masalah biasa:** RM50/hari ÷ 8 poster = RM6.25/poster/hari.
> Terlalu sedikit — Meta tak dapat belajar, dan ia akan bunuh 6 poster awal
> sebelum sempat beri data.

### Syarat 2 — Jangan sentuh selama 3 hari

Meta perlukan **3 hari** fasa pembelajaran. Kalau anda edit/tukar bajet setiap hari,
data kacau dan keputusan tak boleh dipercayai.

---

## 2. CARA UJI (LANGKAH DEMI LANGKAH)

```
1. Buat 1 Ad Set (audiens yang sudah terbukti murah)
2. Masukkan 8 Ads (8 angle di bawah)
3. Bajet: RM160/hari (RM20/poster)
4. JANGAN sentuh selama 3 hari
5. Hari 4: semak setiap poster
6. Hari 5-7: matikan yang lemah, kekalkan 2-3 terbaik
7. Hari 8: duplicate pemenang ke ad set sendiri → skala
```

### Peraturan mematikan poster

| Keadaan | Tindakan |
|---|---|
| 0 hasil selepas belanja RM40 | ⛔ Matikan |
| Kos/perbualan > 2x purata | ⛔ Matikan |
| Kos/perubualan < purata | ✅ Kekalkan |
| CTR < 0.5% | ⛔ Matikan (poster tak menarik) |
| CPM > RM50 | 🟡 Semak audiens |

## 5. SELEPAS DAPAT PEMENANG

Jangan terus naik bajet pada ad set ujian. Ini cara betul:

```
1. Ambil 2-3 poster terbaik
2. Duplicate ke AD SET BAHARU (bersih, tiada sejarah)
3. Bajet baru: RM100/hari untuk 2-3 poster
4. Naik 20% setiap 3 hari (bukan 2x sekali gus)
5. Uji angle baru dalam ad set ujian yang sama
```

> **Peraturan skala:** naik bajet maksimum **20–30% setiap 3 hari**.
> Naik terlalu cepat = kos melonjak (audiens tepu).

### 3 poster untuk mula dahulu (kalau bajet terhad)
Kalau bajet RM60/hari, uji **3 poster** sahaja dahulu:
1. **Angle 1** — Lari duit (ketakutan terkuat)
2. **Angle 3** — Harga (soalan paling kerap)
3. **Angle 8** — Ada tanah? (terus kepada sasaran)

Kemudian putar set 3 poster yang lain.
