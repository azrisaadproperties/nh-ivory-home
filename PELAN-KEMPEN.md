## 1. STRATEGI: IKUT KEKUATAN

Jangan agih bajet sama rata. Agih ikut di mana anda paling kuat.

| Saluran | Peratus | Jumlah (bajet RM7,000) | Sebab |
|---|---|---|---|
| **Meta — Direct Lead Gen** | **70%** | RM4,900 | Kekuatan anda. Terus cari lead baharu. |
| **Meta — Retargeting** | **15%** | RM1,050 | Mudah, murah, kadar tukar tinggi |
| **Google Search** | **15%** | RM1,050 | Niat tinggi. Mula kecil, belajar dahulu. |
| Jumlah | 100% | **RM7,000** | |

> **Prinsip:** 70% pada apa yang anda sudah mahir. 30% untuk belajar perkara baharu
> dengan risiko terkawal.

> **Nota ejen (komisen 2%):** Kos iklan adalah **sama** sama ada anda jual rumah RM150k
> atau RM800k — tetapi komisen 5x lebih besar. **Sasarkan projek bernilai tinggi**
> (banglo 2 tingkat, spesifikasi premium). Tapis lead untuk bajet lebih tinggi.
> Lihat `BAJET-MARKETING.md` seksyen 5 untuk kiraan penuh.

## 2. META ADS — DIRECT LEAD GEN (TERAS)

### 2.1 Struktur kempen

```
Kempen: [LEAD] Bina Rumah — Perak/Kedah/Penang
├── Ad Set 1: Perak — Broad
├── Ad Set 2: Perak — Interest Hartanah
├── Ad Set 3: Kedah + Penang — Broad
└── Ad Set 4: Penjawat Awam (LPPSA)
```

| Tetapan | Nilai |
|---|---|
| Objective | **Leads** |
| Conversion event | **Lead** (pasang Meta Pixel dahulu) |
| Optimization | Conversions |
| Bid strategy | Lowest cost (mula), kemudian Cost per result goal |
| Placement | Advantage+ (automatik) |
| Budget | CBO (Campaign Budget Optimization) |

### 2.2 Audiens

**Lokasi:**
- Perak (utama) — Ipoh, Seri Iskandar, Manjung, Kuala Kangsar, Taiping, Teluk Intan, Kampar, Batu Gajah
- Kedah — Alor Setar, Sungai Petani, Kulim
- Pulau Pinang — Seberang Perai

**Umur:** 30 – 60
**Jantina:** Semua (keputusan biasanya pasangan bersama)

**Interest (Ad Set 2):**
```
Hartanah / Real estate
Property investment
Home improvement
Construction
Tanah / Land
Perbankan / Loan
LPPSA
```
**Behavior:**
```
Small business owners
Frequent travelers (petanda kemampuan)
```

**Custom Audience (kalau ada):**
- Senarai pelanggan lama (untuk lookalike 1%)

> **Tip:** Broad targeting (tanpa interest) biasanya lebih murah sekarang kerana
> algoritma Meta sudah pandai. Uji broad vs interest.

### 2.3 Format kreatif (ikut keutamaan)

| # | Format | Sebab | Kadar tukar |
|---|---|---|---|
| 1 | **Video testimoni pelanggan** | Paling dipercayai | Tertinggi |
| 2 | **Video walkthrough rumah siap** | Tunjuk kualiti kerja | Tinggi |
| 3 | **Carousel gambar projek** | Tunjuk kepelbagaian reka bentuk | Sederhana |
| 4 | **Gambar tunggal + teks kuat** | Murah, cepat diuji | Sederhana |
| 5 | **Video "kos vs hasil"** | Jawab soalan harga | Tinggi |

**Video testimoni yang kita ada (guna ini dahulu):**
- Banglo Purewhite — Teluk Intan
- Banglo Stellar — Beruas
- Banglo Amaya — Chemor
- Banglo Audela — Batu Gajah

### 2.4 Copywriting — Hook (Bahasa Melayu)

Ini yang menentukan sama ada orang berhenti scroll. Uji 3–5 hook berbeza.

**Hook ketakutan:**
```
"Kontraktor lari duit? Ini cara kami lindungi wang anda."
```

**Hook harga:**
```
"Bina rumah atas tanah sendiri bermula RM13X,000. Tunai atau loan."
```

**Hook soalan:**
```
"Ada tanah sendiri tapi tak tahu macam mana nak mula bina?"
```

**Hook bukti sosial:**
```
"2000++ pelanggan. 4.9 bintang di Google. Ini projek terbaru kami."
```

**Hook lokaliti:**
```
"Kami bina rumah di seluruh Perak. Tengok projek di [kawasan] anda."
```

**Hook penjawat awam:**
```
"Penjawat awam: guna LPPSA untuk bina rumah sendiri. Ansuran potong gaji."
```

**Struktur copy lengkap:**
```
[HOOK — 1 baris kuat]
[KETAKUTAN — 2 baris: apa yang mereka risau]
[PENYELESAIAN — 3 baris: apa kita buat]
[BUKTI — 1 baris: projek/pelanggan/review]
[CTA — 1 baris: apa nak buat sekarang]
```

**Contoh penuh:**
```
Ada tanah sendiri tapi takut nak mula bina?

Risau kontraktor lari duit, kos naik tiba-tiba, atau projek terbengkalai.
Kami faham — sebab itu kami bayar ikut milestone, bukan bayaran awal besar.

Harga telus, kontrak bertulis, siap ikut jadual.
2000++ pelanggan · 4.9★ Google · CIDB G4 berdaftar.

Isi 3 maklumat sahaja — kami WhatsApp sebut harga percuma.
```

### 2.5 Destinasi lead

| Pilihan | Baik | Tidak baik |
|---|---|---|
| **WhatsApp** (cadangan) | Kadar tukar tinggi, perbualan segera | Perlu respons pantas |
| Borang dalam Meta (Instant Form) | Data automatik masuk | Lead lebih sejuk |
| Laman web kita | Tracking penuh, boleh retarget | Kadar tukar rendah sedikit |

> **Cadangan:** guna **WhatsApp** sebagai destinasi utama. Laman web kita sudah
> siap sedia dengan butang WhatsApp + borang 3 medan.

## 3. META RETARGETING (LANGKAH MUDAH)

Anda faham flow — ini langkah tepatnya.

### 3.1 Buat 3 Custom Audience

**Business Settings → Audiences → Create Audience → Custom Audience**

| # | Jenis | Tetapan | Tempoh |
|---|---|---|---|
| 1 | **Website** | Semua pelawat yang **TIDAK** hantar borang | 30 hari |
| 2 | **Video** | Tonton 50%+ video testimoni | 90 hari |
| 3 | **Engagement** | Suka/komen/kongsi iklan & Page | 365 hari |

> **Untuk #1:** perlu Meta Pixel dahulu. Kalau belum ada, mula dengan #2 dan #3.

### 3.2 Struktur kempen retargeting

```
Kempen: [RETARGET] Bina Rumah
├── Ad Set 1: Pelawat laman 30 hari (belum isi borang)
├── Ad Set 2: Penonton video 50%
└── Ad Set 3: Engagement Page/IG
```

| Tetapan | Nilai |
|---|---|
| Objective | Leads |
| Budget | RM30–50/hari (kecil sahaja) |
| Frequency cap | 2–3 kali seminggu |
| Exclude | **Yang sudah isi borang** (buat audience "Lead" dan exclude) |

### 3.3 Kreatif retargeting (berbeza dari prospecting)

Jangan guna iklan sama. Orang ini sudah nampak anda — sekarang jawab keraguan mereka.

| Jenis | Contoh mesej |
|---|---|
| **Jawab FAQ** | "Berapa kos bina rumah sekaki persegi? Ini jawapannya." |
| **Testimoni** | "Tengok apa kata pelanggan kami di [kawasan]." |
| **Urgency** | "Slot projek bulan ini tinggal 2. Konsultasi percuma." |
| **Bandingkan** | "Tunai vs Loan vs LPPSA — mana sesuai untuk anda?" |
| **Bukti proses** | "Ini cara kami bayar ikut milestone. Tiada risiko." |

> **Tip:** Retargeting biasanya **50% lebih murah** dan kadar tukar **2–3x lebih tinggi**
> berbanding prospecting. Tapi audiens kecil — jadi belanja kecil sahaja.

## 4. GOOGLE ADS — PANDUAN PEMULA LENGKAP

Anda belum pernah setup. Ikut langkah ini tepat.

### 4.1 Persediaan (sebelum mula)

| Item | Status |
|---|---|
| Akaun Google | Ada (untuk GA4) |
| GA4 dipasang di laman | ✅ Sudah |
| Laman web | ✅ Sudah |
| Kad kredit/debit | Perlu |
| **Bajet mula** | **RM30–50/hari** |

### 4.2 Langkah setup

**Langkah 1 — Buka akaun**
1. Buka **https://ads.google.com**
2. Log masuk dengan akaun Google yang sama dengan GA4
3. Google akan cuba pujuk **"Smart Campaign"** — **JANGAN terima**
4. Klik **"Switch to Expert Mode"** di bawah
5. Pilih **"Create an account without a campaign"**

**Langkah 2 — Tetapan akaun**
| Medan | Isi |
|---|---|
| Currency | `Malaysian Ringgit (RM)` |
| Time zone | `Malaysia (GMT+08:00)` |
| Billing | Kad kredit/debit |

**Langkah 3 — Pautkan GA4 (PENTING)**
1. **Tools & Settings → Linked accounts → Google Analytics**
2. Klik **Link** → pilih property GA4 anda
3. Ini benarkan anda **import conversion dari GA4** tanpa pasang tag tambahan

**Langkah 4 — Tandakan conversion dalam GA4**
1. Buka **GA4 → Admin → Events**
2. Cari event **`lead`** → tandakan sebagai **conversion**
3. Cari event **`contact`** → tandakan sebagai conversion juga
4. Tunggu 24 jam, kemudian di Google Ads: **Tools → Conversions → Import → GA4**

> Ini cara paling mudah untuk pemula — tiada kod tambahan diperlukan.

**Langkah 5 — Buat kempen**
1. **Campaigns → New campaign**
2. Objective: **Leads**
3. Campaign type: **Search**
4. Goal: **Website leads**

**Langkah 6 — Tetapan kempen**
| Medan | Isi |
|---|---|
| Campaign name | `[SEARCH] Bina Rumah — Perak` |
| Networks | **Google Search sahaja** (matikan Display Network) |
| Locations | Perak, Kedah, Pulau Pinang |
| Location option | **"Presence: People in your targeted locations"** |
| Languages | Bahasa Melayu, English |
| Bidding | **Maximize Clicks** dahulu (mula), kemudian Maximize Conversions |
| Budget | RM30–50/hari |

## 6. KPI & KEPUTUSAN

Semak setiap **minggu** (bukan setiap hari — terlalu awal untuk data bermakna):

| Metrik | Sasaran | Jika gagal |
|---|---|---|
| CPL Meta | < RM70 | Tukar kreatif / hook |
| CPL Google | < RM120 | Tukar keyword / negative |
| CTR iklan | > 1.5% | Tukar visual |
| Lawatan → lead | > 6% | Uji tawaran di laman |
| **Lead → temujanji** | **> 20%** | Perbaiki respons WhatsApp |
| **Temujanji → jualan** | **> 33%** | Latih pasukan jualan |

**Peraturan penting:** jangan tukar apa-apa selama **3 hari** selepas ubah.
Algoritma perlu masa belajar. Terlalu banyak ubah = data kacau.
